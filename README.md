## Desarrollo rápido (Android)

Para acelerar compilación y ejecución en desarrollo:

1. Abre PowerShell en la raíz del proyecto.
2. Ejecuta:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\dev_fast.ps1
```

Opcionales:

- Limpiar antes de correr:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\dev_fast.ps1 -Clean
```

- Seleccionar dispositivo específico:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\dev_fast.ps1 -TargetDevice emulator-5554
```
